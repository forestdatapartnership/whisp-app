# Termos de uso da API Whisp

*Esta tradução é fornecida apenas para fins informativos. Em caso de divergência, prevalece a versão em inglês.*

Este acordo rege o uso do aplicativo de software da API Whisp ("interface de programação de aplicações"), de propriedade da Organização das Nações Unidas para a Alimentação e a Agricultura (FAO), que o hospeda e administra.

## Acordo

Ao usar a API Open Foris Whisp ("Whisp"), você reconhece e concorda que estes Termos de uso (que a FAO pode alterar periodicamente e sem aviso prévio) se aplicam. Se você não concorda com estes Termos de uso, não acesse nem utilize o Whisp de qualquer outra forma.

## Acesso

A FAO se reserva o direito de, a qualquer momento e a seu exclusivo critério, modificar, suspender temporariamente ou encerrar permanentemente o Whisp, incluindo qualquer meio de acessá-lo ou utilizá-lo, com ou sem aviso prévio aos usuários.

## Dados de entrada dos usuários

O Whisp processa todos os dados de acordo com as regras, políticas e procedimentos internos da FAO.

Os usuários mantêm a propriedade de todos os dados enviados por meio do Whisp e são os únicos responsáveis por garantir que possuem os direitos legais para carregar e processar esses dados. O envio de dados não transfere nenhum direito de propriedade intelectual à FAO.

Os usuários devem se abster de enviar qualquer informação de identificação pessoal, incluindo dados pessoais sensíveis.

### Processamento regular de dados

O Whisp permite que os usuários enviem geodados, incluindo geometrias vetoriais, que podem ser processados por meio do Google Earth Engine (GEE), um serviço em nuvem de terceiros administrado pelo Google. Os dados transmitidos ao GEE podem ser temporariamente armazenados em cache e processados em centros de dados em nuvem. A FAO não armazena nem retém os geodados enviados pelos usuários.

### Processamento de dados sensíveis

A geometria enviada pelos usuários e compartilhada com o GEE não permite identificar nenhuma pessoa em particular. O processamento dos geodados dos usuários para o Whisp é realizado em servidores mantidos na Europa. A FAO não armazenará nem reterá os geodados dos usuários.

A FAO protege a privacidade dos usuários ao acessar os geodados transmitindo ao GEE apenas informações geográficas aproximadas, acompanhadas de dados de mascaramento adicionais para impedir a identificação da área de interesse real. Essas informações são usadas exclusivamente para facilitar o processamento e não são armazenadas nem retidas permanentemente pelo GEE.

Os dados tabulares vinculados às informações geográficas dos usuários são apenas armazenados temporariamente em cache e não são armazenados permanentemente. Esses dados não são compartilhados com o GEE em nenhuma etapa do fluxo de processamento.
